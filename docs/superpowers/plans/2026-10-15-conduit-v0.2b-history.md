# Conduit V0.2-B Implementation Plan: device history query and charts

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `GET /api/v1/devices/{deviceKey}/history` (raw or server-side aggregated history of up to 8 properties) and a 「历史」 tab on the device detail page with one linked ECharts chart per property, plus the simulator fixes needed to demo and deploy it (enum state `st`, MQTT connect retry).

**Architecture:** In `conduit-server`'s `telemetry` package, a parameterized `InfluxClient.querySql(db, sql, params)` (POST `/api/v3/query_sql`) and a 60 s `InfluxSchema` column cache feed a `HistoryService`: it resolves each property's type (thing model first, then the InfluxDB column type), counts points with one SQL, and then runs either a raw query or a `date_bin` aggregation whose bucket comes from the pure `BucketPolicy`. All SQL text comes from the pure `HistoryQueryBuilder`; request values travel only as `$params`. The Vue side adds pure helpers (`historyRange`, `historyChart`, `historyProperties`), a visibility-aware poller and a `HistoryPanel` component that uses on-demand ECharts 5.6.0 modules.

**Tech Stack:** Java 21, Spring Boot 3.5.6, InfluxDB 3 Core 3.12.0 (HTTP API v3, SQL), PostgreSQL 16, Redis 7.4, Testcontainers, HiveMQ MQTT client, Vue 3.5 + TypeScript + Element Plus 2.11 + ECharts 5.6.0 + Vitest + @vue/test-utils.

**Governing spec:** `docs/superpowers/specs/2026-10-15-conduit-v0.2b-history-design.md` (behavior); `docs/superpowers/specs/2026-10-14-conduit-v0.1-design.md` (conventions).

**InfluxDB 3 facts this plan relies on** (probed against a real `influxdb:3.12.0-core`; Task 1's `InfluxClientIT` pins every row marked ✓):

| Behavior | Observed |
|---|---|
| ✓ Parameterized query | `POST /api/v3/query_sql` with JSON body `{"db","q","params":{...},"format":"json"}`; `$name` placeholders. String params work in comparisons (`tenant_id = $tenant`, `device_key = $device`) |
| ✓ Time params | ISO-8601 UTC strings with millis, e.g. `"from":"2025-10-14T00:00:00.000Z"` used as `time >= $from AND time < $to` give correct results |
| Time params, wrong way | `to_timestamp_millis($from)` with a numeric param returns HTTP 200 with an **empty body** (silently no rows). Never use it |
| ✓ Response | JSON array of row objects; `[]` when empty. `time` / `date_bin` values are ISO strings **without zone** (e.g. `"2025-10-14T00:05:00"`) and are UTC |
| ✓ Count | `SELECT COUNT("Ua") AS "Ua", COUNT("st") AS "st" FROM property WHERE …` → `[{"Ua":10,"st":10}]` (non-null counts) |
| ✓ Aggregation | `SELECT date_bin(INTERVAL '300 seconds', time) AS t, avg("Ua") …, min(…), max(…), selector_last("st", time)['value'] AS … FROM property WHERE … GROUP BY 1 ORDER BY 1` works; `selector_last` works for Int64 and Boolean columns |
| ✓ Bucket origin | `date_bin` aligns to 1970-01-01, so the first bucket may start before `from` (from = 00:03 with 5-minute buckets → first bucket 00:00) |
| ✓ Raw | `SELECT time, "Ua", "on" FROM property WHERE … ORDER BY time` → `{"time":"…","Ua":220.5,"on":true}`; a column without a value in that row is omitted or `null` (handle both) |
| ✓ Schema | `information_schema.columns` (`table_name = 'property'`) `data_type`: `Float64`, `Int64`, `Boolean`, `Utf8`, `Dictionary(Int32, Utf8)` (tags), `Timestamp(ns)` |
| ✓ Unknown column | `Schema error: No field named "Zz"…` returned as HTTP **500** → only query columns that `InfluxSchema` confirms |
| ✓ Unknown database | HTTP **404** `database not found` |

**Decisions recorded here:**
- The existing GET `querySql(db, sql)` stays as it is (test support and the schema query use it). The schema SQL contains no request value, so it needs no params.
- `InfluxSchema.lookup` is `synchronized`. A reload holds the lock for one HTTP call. That is acceptable for this single-instance personal platform, and it stops concurrent requests from each issuing their own reload.
- "Forced refresh once" means at most one reload per `lookup` call. A request that names a never-reported column therefore costs one extra `information_schema` query, and the column is then treated as missing (empty series).
- `ColumnType.of`: `Float64` → FLOAT; `Int64`/`UInt64` → INTEGER; `Boolean` → BOOLEAN; `Utf8`/`LargeUtf8`/`Dictionary(…)` → STRING; anything else (e.g. `Timestamp(ns)`) → OTHER.

```java
package dev.conduit.server.telemetry;

import java.time.Instant;
import java.time.LocalDateTime;
import java.time.OffsetDateTime;
import java.time.ZoneOffset;
import java.time.format.DateTimeFormatter;
import java.time.format.DateTimeParseException;
import java.time.temporal.TemporalAccessor;

/**
 * InfluxDB 3 SQL 的时间换算。查询参数用带毫秒的 ISO-8601 UTC 字符串（如 2025-10-14T00:00:00.000Z，
 * 数值参数配合 to_timestamp_millis 会静默返回空结果，不能用）；查询结果中的 time / date_bin 值是
 * 不带时区的 UTC 字符串（如 2025-10-14T00:05:00），这里统一换算为毫秒时间戳。
 */
public final class InfluxTime {

    private static final DateTimeFormatter PARAM =
            DateTimeFormatter.ofPattern("uuuu-MM-dd'T'HH:mm:ss.SSS'Z'").withZone(ZoneOffset.UTC);

    private InfluxTime() {
    }

    /**
     * 毫秒时间戳 → SQL 时间参数。
     *
     * @param epochMillis 毫秒时间戳
     * @return 形如 2025-10-14T00:00:00.000Z 的字符串，可直接用于 {@code time >= $from}
     */
    public static String iso(long epochMillis) {
        return PARAM.format(Instant.ofEpochMilli(epochMillis));
    }

    /**
     * 查询结果中的时间值 → 毫秒时间戳。不带时区的字符串按 UTC 解释；带 Z 或偏移量的也接受；
     * 超过毫秒精度的小数部分直接截断。
     *
     * @param influxTime 结果行中的 time 或 date_bin 列的值
     * @return 毫秒时间戳
     * @throws IllegalArgumentException 值不是可识别的时间字符串
     */
    public static long epochMillis(Object influxTime) {
        if (!(influxTime instanceof String s) || s.isBlank()) {
            throw new IllegalArgumentException("Not an InfluxDB time value: " + influxTime);
        }
        try {
            TemporalAccessor parsed = DateTimeFormatter.ISO_DATE_TIME.parseBest(s, OffsetDateTime::from,
                    LocalDateTime::from);
            Instant instant = parsed instanceof OffsetDateTime odt
                    ? odt.toInstant()
                    : ((LocalDateTime) parsed).toInstant(ZoneOffset.UTC);
            return instant.toEpochMilli();
        } catch (DateTimeParseException e) {
            throw new IllegalArgumentException("Not an InfluxDB time value: " + influxTime, e);
        }
    }
}
```

```java
 * property 表的列名与列类型缓存（来自 information_schema.columns），写入后 60 秒过期。
 * 查询中出现缓存里没有的列时强制刷新一次（该列可能刚被首次写入）；刷新后仍没有，即视为从未上报。
 * 历史查询只拼接本缓存确认存在的列名：InfluxDB 对未知列返回 500（Schema error），不能把它当作「空曲线」。
 */
@Component
public class InfluxSchema {

    static final Duration TTL = Duration.ofSeconds(60);
    static final String COLUMNS_SQL =
            "SELECT column_name, data_type FROM information_schema.columns WHERE table_name = 'property'";

    /** 历史查询关心的列类型，由 InfluxDB（Arrow）类型归类而来。 */
    public enum ColumnType {
        FLOAT, INTEGER, BOOLEAN, STRING, OTHER;

        /**
         * 归类 information_schema 中的 data_type。
         *
         * @param arrowType 如 Float64、Int64、Boolean、Utf8、Dictionary(Int32, Utf8)、Timestamp(ns)
         * @return Float64 → FLOAT；Int64/UInt64 → INTEGER；Boolean → BOOLEAN；Utf8/LargeUtf8/Dictionary(…)（标签列）
         *         → STRING；其余 → OTHER
         */
        static ColumnType of(String arrowType) {
            if (arrowType == null) {
                return OTHER;
            }
            return switch (arrowType) {
                case "Float64" -> FLOAT;
                case "Int64", "UInt64" -> INTEGER;
                case "Boolean" -> BOOLEAN;
                case "Utf8", "LargeUtf8" -> STRING;
                default -> arrowType.startsWith("Dictionary(") ? STRING : OTHER;
            };
        }
    }

    /** 一次加载的结果与加载时刻。 */
    private record Snapshot(Map<String, ColumnType> columns, Instant loadedAt) {
    }

    private final InfluxClient client;
    private final InfluxProperties props;
    private final Clock clock;
    private Snapshot snapshot;

    public InfluxSchema(InfluxClient client, InfluxProperties props, Clock clock) {
        this.client = client;
        this.props = props;
        this.clock = clock;
    }

    /**
     * 查询若干列的类型。缓存为空或已过期时重新加载；有缓存中不存在的列时再强制刷新一次（每次调用最多加载一次）。
     * InfluxDB 的异常原样抛出，由调用方映射为 503/500。
     *
     * @param identifiers 已通过标识符校验的列名
     * @return 按 identifiers 顺序的「列名 → 类型」，不存在的列不在结果中
     */
    public synchronized Map<String, ColumnType> lookup(Collection<String> identifiers) {
        boolean reloaded = false;
        if (snapshot == null || !clock.instant().isBefore(snapshot.loadedAt().plus(TTL))) {
            reload();
            reloaded = true;
        }
        if (!reloaded && !snapshot.columns().keySet().containsAll(identifiers)) {
            reload();
        }
        Map<String, ColumnType> result = new LinkedHashMap<>();
        for (String id : identifiers) {
            ColumnType type = snapshot.columns().get(id);
            if (type != null) {
                result.put(id, type);
            }
        }
        return result;
    }

    /** 从 information_schema 重新加载 property 表的全部列。 */
    private void reload() {
        List<Map<String, Object>> rows = client.querySql(props.database(), COLUMNS_SQL);
        Map<String, ColumnType> columns = new HashMap<>();
        for (Map<String, Object> row : rows) {
            columns.put(String.valueOf(row.get("column_name")), ColumnType.of((String) row.get("data_type")));
        }
        snapshot = new Snapshot(Map.copyOf(columns), clock.instant());
    }
}
```

```java
package dev.conduit.server.telemetry;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;

import java.io.IOException;
import java.io.InterruptedIOException;
import java.io.UncheckedIOException;
import java.net.URI;
import java.net.URLEncoder;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * InfluxDB 3 Core HTTP API（v3）的最小客户端。IO 失败抛 UncheckedIOException；非 2xx 抛 InfluxHttpException，
 * 唯一例外是写入时的部分行被拒（400 + partial write JSON），此时返回被拒的行。
 */
public class InfluxClient implements AutoCloseable {

    /** 被拒的一行；lineNumber 从 1 开始，对应提交顺序。 */
    public record LineError(int lineNumber, String message) {
    }

    static final String PARTIAL_WRITE = "partial write of line protocol occurred";
    private static final Duration CONNECT_TIMEOUT = Duration.ofSeconds(5);
    private static final Duration REQUEST_TIMEOUT = Duration.ofSeconds(10);
    private static final TypeReference<List<Map<String, Object>>> ROWS = new TypeReference<>() {
    };

    private final String baseUrl;
    private final String authorization;
    private final HttpClient http;
    private final ObjectMapper mapper = new ObjectMapper();

    public InfluxClient(URI baseUrl, String token) {
        String url = baseUrl.toString();
        this.baseUrl = url.endsWith("/") ? url.substring(0, url.length() - 1) : url;
        this.authorization = "Bearer " + token;
        this.http = HttpClient.newBuilder().connectTimeout(CONNECT_TIMEOUT).build();
    }

    /** 写入行协议（accept_partial 默认开启：合格行照常写入）。全部成功返回空列表。 */
    public List<LineError> writeLines(String db, List<String> lines) {
        HttpResponse<String> response = send(HttpRequest.newBuilder(
                        uri("/api/v3/write_lp", "db", db, "precision", "millisecond"))
                .header("Content-Type", "text/plain; charset=utf-8")
                .POST(HttpRequest.BodyPublishers.ofString(String.join("\n", lines), StandardCharsets.UTF_8)));
        int status = response.statusCode();
        if (status == 204 || status == 200) {
            return List.of();
        }
        if (status == 400) {
            List<LineError> errors = partialWriteErrors(response.body());
            if (errors != null) {
                return errors;
            }
        }
        throw new InfluxHttpException(status, response.body());
    }

    /** 不带参数的 SQL 查询（GET）；只用于不含任何外部输入的 SQL。 */
    public List<Map<String, Object>> querySql(String db, String sql) {
        return rows(send(HttpRequest.newBuilder(
                uri("/api/v3/query_sql", "db", db, "q", sql, "format", "json")).GET()));
    }

    /**
     * 参数化 SQL 查询（POST /api/v3/query_sql，format=json）。SQL 中用 $name 引用 params 中的值：
     * 字符串参数可直接用于比较；时间参数必须是 {@link InfluxTime#iso(long)} 生成的 ISO-8601 UTC 字符串。
     *
     * @param db     数据库名
     * @param sql    SQL 文本，不得拼接任何请求值
     * @param params 参数名 → 值
     * @return 结果行（列名 → 值），无结果为空列表
     * @throws InfluxHttpException  InfluxDB 返回非 200
     * @throws UncheckedIOException 连接失败、超时等 IO 错误
     */
    public List<Map<String, Object>> querySql(String db, String sql, Map<String, Object> params) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("db", db);
        body.put("q", sql);
        body.put("params", params);
        body.put("format", "json");
        return rows(send(HttpRequest.newBuilder(uri("/api/v3/query_sql"))
                .header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString(json(body), StandardCharsets.UTF_8))));
    }

    /** 保留期只能在建库时设置；库已存在（409）视为成功。 */
    public void createDatabaseIfMissing(String db, String retention) {
        HttpResponse<String> response = send(HttpRequest.newBuilder(uri("/api/v3/configure/database"))
                .header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString(
                        json(Map.of("db", db, "retention_period", retention)), StandardCharsets.UTF_8)));
        int status = response.statusCode();
        if (status / 100 == 2 || status == 409) {
            return;
        }
        throw new InfluxHttpException(status, response.body());
    }

    @Override
    public void close() {
        http.close();
    }

    /** 解析查询响应：非 200 抛 InfluxHttpException；空响应体视为无结果。 */
    private List<Map<String, Object>> rows(HttpResponse<String> response) {
        if (response.statusCode() != 200) {
            throw new InfluxHttpException(response.statusCode(), response.body());
        }
        String body = response.body();
        if (body == null || body.isBlank()) {
            return List.of();
        }
        try {
            return mapper.readValue(body, ROWS);
        } catch (JsonProcessingException e) {
            throw new IllegalStateException("Unexpected InfluxDB query response: " + e.getOriginalMessage(), e);
        }
    }

    private String json(Object value) {
        try {
            return mapper.writeValueAsString(value);
        } catch (JsonProcessingException e) {
            throw new IllegalStateException(e);
        }
    }

    private List<LineError> partialWriteErrors(String body) {
        try {
            JsonNode root = mapper.readTree(body);
            if (root == null || !PARTIAL_WRITE.equals(root.path("error").asText()) || !root.path("data").isArray()) {
                return null;
            }
            List<LineError> errors = new ArrayList<>();
            for (JsonNode item : root.get("data")) {
                errors.add(new LineError(item.path("line_number").asInt(-1), item.path("error_message").asText("")));
            }
            return errors;
        } catch (JsonProcessingException e) {
            return null;
        }
    }

    private URI uri(String path, String... query) {
        StringBuilder sb = new StringBuilder(baseUrl).append(path);
        for (int i = 0; i < query.length; i += 2) {
            sb.append(i == 0 ? '?' : '&').append(query[i]).append('=')
                    .append(URLEncoder.encode(query[i + 1], StandardCharsets.UTF_8));
        }
        return URI.create(sb.toString());
    }

    private HttpResponse<String> send(HttpRequest.Builder request) {
        try {
            return http.send(request.timeout(REQUEST_TIMEOUT).header("Authorization", authorization).build(),
                    HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8));
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new UncheckedIOException(new InterruptedIOException("Interrupted while calling InfluxDB"));
        }
    }
}
```

```java
package dev.conduit.server.telemetry;

import java.time.Duration;
import java.util.List;

/**
 * 历史查询的时间桶策略（V0.2-B spec 2.2）：每条曲线最多 1000 个点，聚合时从固定档位中取能满足上限的最小桶。
 * 档位固定，相邻请求（如自动刷新）的桶边界一致，曲线不会跳动。
 */
public final class BucketPolicy {

    /** 每个测点的点数上限：原始点数都不超过它时走原始模式，否则聚合后的桶数不超过它。 */
    public static final int MAX_POINTS = 1000;

    /** 桶档位：1 秒、5 秒、10 秒、30 秒、1 分钟、5 分钟、15 分钟、30 分钟、1 小时、3 小时、6 小时、12 小时。 */
    public static final List<Duration> LADDER = List.of(
            Duration.ofSeconds(1), Duration.ofSeconds(5), Duration.ofSeconds(10), Duration.ofSeconds(30),
            Duration.ofMinutes(1), Duration.ofMinutes(5), Duration.ofMinutes(15), Duration.ofMinutes(30),
            Duration.ofHours(1), Duration.ofHours(3), Duration.ofHours(6), Duration.ofHours(12));

    private BucketPolicy() {
    }

    /**
     * 选择聚合时间桶。
     *
     * @param spanMs 查询跨度 to − from（毫秒）
     * @return 满足 spanMs ≤ 桶 × 1000 的最小档位；跨度超出最大档能覆盖的范围时返回 12 小时
     */
    public static Duration bucketFor(long spanMs) {
        for (Duration bucket : LADDER) {
            if (spanMs <= bucket.toMillis() * MAX_POINTS) {
                return bucket;
            }
        }
        return LADDER.getLast();
    }
}
```

```java
package dev.conduit.server.telemetry;

import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.StringJoiner;
import java.util.regex.Pattern;

/**
 * 生成历史查询的三种 SQL（计数、原始、聚合）及其参数（V0.2-B spec 3）。纯函数。
 * 防注入：列名只接受匹配 {@link #IDENTIFIER} 的标识符并加双引号；租户、产品、设备与时间范围一律经 $参数 传入，
 * SQL 文本中不出现任何请求值。结果列使用按位置编号的别名（n_0、v_0、avg_0、last_1 …），与测点名无关。
 */
public final class HistoryQueryBuilder {

    /** 测点标识符规则，与物模型一致。 */
    public static final Pattern IDENTIFIER = Pattern.compile("^[A-Za-z][A-Za-z0-9_]{0,63}$");

    private static final String WHERE = " FROM property WHERE tenant_id = $tenant AND product_key = $product"
            + " AND device_key = $device AND time >= $from AND time < $to";

    /** 一条 SQL 与它的 $参数。 */
    public record SqlQuery(String sql, Map<String, Object> params) {
    }

    /** 查询范围：租户、产品、设备与半开区间 [from, to)（毫秒）。 */
    public record Scope(long tenantId, String productKey, String deviceKey, long from, long to) {
    }

    /** 聚合查询中的一列：state 为 true 时取桶内最后值，否则取 avg/min/max。 */
    public record AggColumn(String identifier, boolean state) {
    }

    private HistoryQueryBuilder() {
    }

    /**
     * 计数 SQL：每列在范围内的非空点数，结果为一行，别名 n_i。
     *
     * @param scope   查询范围
     * @param columns 已确认存在的列，至少一个
     */
    public static SqlQuery count(Scope scope, List<String> columns) {
        requireColumns(columns);
        StringJoiner select = new StringJoiner(", ", "SELECT ", "");
        for (int i = 0; i < columns.size(); i++) {
            select.add("COUNT(" + quote(columns.get(i)) + ") AS " + quote(countAlias(i)));
        }
        return new SqlQuery(select + WHERE, params(scope));
    }

    /**
     * 原始 SQL：按时间升序返回每行的 time 与各列值（别名 v_i，行内无值时为 null 或缺省）。
     *
     * @param scope   查询范围
     * @param columns 已确认存在的列，至少一个
     */
    public static SqlQuery raw(Scope scope, List<String> columns) {
        requireColumns(columns);
        StringJoiner select = new StringJoiner(", ", "SELECT time, ", "");
        for (int i = 0; i < columns.size(); i++) {
            select.add(quote(columns.get(i)) + " AS " + quote(valueAlias(i)));
        }
        return new SqlQuery(select + WHERE + " ORDER BY time", params(scope));
    }

    /**
     * 聚合 SQL：按 date_bin（原点 1970-01-01）分桶，桶起点列为 t。数值列输出 avg_i/min_i/max_i，
     * 状态列输出 last_i（selector_last 取桶内时间最大的值）。首桶可能早于 from。
     *
     * @param scope         查询范围
     * @param columns       已确认存在的列，至少一个
     * @param bucketSeconds 桶宽（秒），来自 {@link BucketPolicy}，必须为正数
     */
    public static SqlQuery aggregate(Scope scope, List<AggColumn> columns, long bucketSeconds) {
        if (columns == null || columns.isEmpty()) {
            throw new IllegalArgumentException("At least one column is required");
        }
        if (bucketSeconds <= 0) {
            throw new IllegalArgumentException("Bucket must be positive: " + bucketSeconds);
        }
        StringJoiner select = new StringJoiner(", ",
                "SELECT date_bin(INTERVAL '" + bucketSeconds + " seconds', time) AS t, ", "");
        for (int i = 0; i < columns.size(); i++) {
            String column = quote(columns.get(i).identifier());
            if (columns.get(i).state()) {
                select.add("selector_last(" + column + ", time)['value'] AS " + quote(lastAlias(i)));
            } else {
                select.add("avg(" + column + ") AS " + quote(avgAlias(i)));
                select.add("min(" + column + ") AS " + quote(minAlias(i)));
                select.add("max(" + column + ") AS " + quote(maxAlias(i)));
            }
        }
        return new SqlQuery(select + WHERE + " GROUP BY 1 ORDER BY 1", params(scope));
    }

    /**
     * 校验并给标识符加双引号。
     *
     * @throws IllegalArgumentException 不匹配 {@link #IDENTIFIER}
     */
    public static String quote(String identifier) {
        if (identifier == null || !IDENTIFIER.matcher(identifier).matches()) {
            throw new IllegalArgumentException("Illegal identifier: " + identifier);
        }
        return '"' + identifier + '"';
    }

    public static String countAlias(int i) {
        return "n_" + i;
    }

    public static String valueAlias(int i) {
        return "v_" + i;
    }

    public static String avgAlias(int i) {
        return "avg_" + i;
    }

    public static String minAlias(int i) {
        return "min_" + i;
    }

    public static String maxAlias(int i) {
        return "max_" + i;
    }

    public static String lastAlias(int i) {
        return "last_" + i;
    }

    private static void requireColumns(List<String> columns) {
        if (columns == null || columns.isEmpty()) {
            throw new IllegalArgumentException("At least one column is required");
        }
    }

    /** 范围参数：tenant_id 是字符串标签，按字符串传；时间用 ISO-8601 UTC。 */
    private static Map<String, Object> params(Scope scope) {
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("tenant", Long.toString(scope.tenantId()));
        params.put("product", scope.productKey());
        params.put("device", scope.deviceKey());
        params.put("from", InfluxTime.iso(scope.from()));
        params.put("to", InfluxTime.iso(scope.to()));
        return params;
    }
}
```

```java
    public static final long MAX_SPAN_MS = 30L * 24 * 3_600_000L;
    public static final long DEFAULT_SPAN_MS = 3_600_000L;
    /** 表 property 的时间列与标签列，不是测点。 */
    static final Set<String> RESERVED = Set.of("time", "tenant_id", "product_key", "device_key");

    /**
     * 解析并校验请求参数。
     *
     * @param properties 逗号分隔的测点标识（各项去掉首尾空白后校验）
     * @param from       起点毫秒，可为 null
     * @param to         终点毫秒，可为 null；from、to 都为 null 时取最近 1 小时
     * @param nowMs      当前时间（毫秒），用于默认范围
     * @return 校验后的请求
     * @throws ApiException 400：测点为空、超过 8 个、标识不合法或为保留列名；只给了一个时间；from ≥ to；
     *                      跨度不在 1 分钟～30 天
     */
    public static HistoryRequest parse(String properties, Long from, Long to, long nowMs) {
        List<String> ids = parseProperties(properties);
        if ((from == null) != (to == null)) {
            throw ApiException.badRequest("from 与 to 须同时提供");
        }
        long start = from == null ? nowMs - DEFAULT_SPAN_MS : from;
        long end = to == null ? nowMs : to;
        if (start >= end) {
            throw ApiException.badRequest("from 须小于 to");
        }
        long span = end - start;
        if (span < MIN_SPAN_MS || span > MAX_SPAN_MS) {
            throw ApiException.badRequest("时间跨度须在 1 分钟到 30 天之间");
        }
        return new HistoryRequest(ids, start, end);
    }

    /** 拆分、去空白、去重（保留首次出现的位置）并校验每个标识与个数。 */
    private static List<String> parseProperties(String properties) {
        if (properties == null || properties.isBlank()) {
            throw ApiException.badRequest("properties 不能为空");
        }
        Set<String> ids = new LinkedHashSet<>();
        for (String token : properties.split(",", -1)) {
            String id = token.trim();
            if (!HistoryQueryBuilder.IDENTIFIER.matcher(id).matches() || RESERVED.contains(id)) {
                throw ApiException.badRequest("测点标识不合法: " + id);
            }
            ids.add(id);
        }
        if (ids.size() > MAX_PROPERTIES) {
            throw ApiException.badRequest("最多查询 " + MAX_PROPERTIES + " 个测点");
        }
        return List.copyOf(ids);
    }
}
```

**Decisions recorded here:**
- Type resolution order: (1) a column whose InfluxDB type is string-like or other (`Utf8`, tags, timestamps) → 400 「文本测点不支持历史曲线」, even if the model says otherwise; (2) a thing-model property: `TEXT` → 400, `DOUBLE`/`INT` → numeric, `BOOL`/`ENUM` → state; (3) no model: `Float64` → `DOUBLE`, `Int64` → `INT`, `Boolean` → `BOOL` (state); (4) no model and no column → empty series with `dataType: null`. The spec defines no type for that case; `null` is honest, and the UI only offers properties that exist in the model or the latest values.
- Missing columns are not counted or queried. When none of the requested columns exist, no SQL runs and every series is empty with `mode: RAW`, `bucketMs: null`.
- Error mapping lives in `HistoryService.influx(...)`: `UncheckedIOException` (connect refused or timeout) and `InfluxHttpException` with status ≥ 500 → `ApiException(503, "时序库暂不可用")`; any other `InfluxHttpException` → `ApiException(500, "历史查询失败")`. The details (which may contain SQL) are only logged. `GlobalExceptionHandler` already renders `ApiException` as ProblemDetail, so it needs no change.
- Parameters are validated before the device lookup, so an invalid request to another tenant's device answers 400, not 404.
- The 503 path is integration-tested by building a `HistoryService` around a real `InfluxClient` that points at a closed port. Stopping the shared InfluxDB container, or replacing the bean, would break or fork the cached Spring test context. The HTTP-5xx and HTTP-4xx mappings are unit-tested with a mocked client.

```java
@Service

    private static final Logger log = LoggerFactory.getLogger(HistoryService.class);
    static final String UNAVAILABLE = "时序库暂不可用";

     * @param exists   InfluxDB 中是否已有该列

    }

    private final InfluxClient client;
    private final InfluxSchema schema;
    private final InfluxProperties props;

    public HistoryService(InfluxClient client, InfluxSchema schema, InfluxProperties props) {
        this.client = client;
        this.schema = schema;

    }

    /**
     * 查询一台设备的历史曲线。
     *
     * @param tenantId 当前租户（作为 SQL 参数，只查本租户数据）
     * @param device   已按租户校验过的设备
     * @param model    产品物模型（按标识索引；没有物模型时为空 Map）
     * @param request  已校验的测点与时间范围
     * @return 与请求测点顺序一致的曲线，所有曲线同一模式与时间桶

     */

                             HistoryRequest request) {
        Map<String, ColumnType> columns = influx(() -> schema.lookup(request.properties()));
        List<Resolved> resolved = request.properties().stream()
                .map(id -> resolve(id, model.get(id), columns.get(id)))
                .toList();
        List<Resolved> present = resolved.stream().filter(Resolved::exists).toList();
        Scope scope = new Scope(tenantId, device.productKey(), device.deviceKey(), request.from(), request.to());

        Map<String, List<List<Object>>> points = Map.of();
        Long bucketMs = null;
        if (!present.isEmpty()) {
            if (fitsRaw(scope, present)) {
                points = queryRaw(scope, present);
            } else {
                Duration bucket = BucketPolicy.bucketFor(request.to() - request.from());
                bucketMs = bucket.toMillis();
                points = queryAggregate(scope, present, bucket);
            }
        }
        boolean aggregated = bucketMs != null;
        Map<String, List<List<Object>>> byId = points;
        List<SeriesView> series = resolved.stream()
                .map(r -> series(r, aggregated ? (r.state() ? Mode.LAST : Mode.AGG) : Mode.RAW,
                        byId.getOrDefault(r.identifier(), List.of())))
                .toList();
        return new HistoryView(device.deviceKey(), request.from(), request.to(), bucketMs, series);
    }

    /**
     * 判定一个测点的类型。列类型为字符串/其他（含标签列）或物模型为 TEXT → 400；有物模型按物模型；
     * 无物模型按列类型（Float64 → DOUBLE，Int64 → INT，Boolean → BOOL）；两者都没有 → dataType 为 null 的空曲线。
     *
     * @param column 列类型，列不存在时为 null
     */
    static Resolved resolve(String identifier, PropertySpec spec, ColumnType column) {
        if (column == ColumnType.STRING || column == ColumnType.OTHER) {
            throw ApiException.badRequest("文本测点不支持历史曲线: " + identifier);
        }
        if (spec != null) {
            if (spec.dataType() == DataType.TEXT) {
                throw ApiException.badRequest("文本测点不支持历史曲线: " + identifier);
            }
            boolean state = spec.dataType() == DataType.BOOL || spec.dataType() == DataType.ENUM;
            return new Resolved(identifier, spec, spec.dataType(), state, column != null);
        }
        if (column == null) {
            return new Resolved(identifier, null, null, false, false);
        }
        DataType type = switch (column) {
            case FLOAT -> DataType.DOUBLE;
            case INTEGER -> DataType.INT;
            case BOOLEAN -> DataType.BOOL;
            case STRING, OTHER -> throw new IllegalStateException("unreachable: " + column);
        };
        return new Resolved(identifier, null, type, type == DataType.BOOL, true);
    }

    /** 统计每个测点在 [from, to) 内的非空点数；全部不超过 {@link BucketPolicy#MAX_POINTS} 时返回 true。 */
    private boolean fitsRaw(Scope scope, List<Resolved> present) {
        List<String> ids = present.stream().map(Resolved::identifier).toList();
        List<Map<String, Object>> rows = run(HistoryQueryBuilder.count(scope, ids));
        Map<String, Object> row = rows.isEmpty() ? Map.of() : rows.getFirst();
        for (int i = 0; i < ids.size(); i++) {
            if (row.get(HistoryQueryBuilder.countAlias(i)) instanceof Number n
                    && n.longValue() > BucketPolicy.MAX_POINTS) {
                return false;
            }
        }
        return true;
    }

    /** 原始模式：逐行取各列的非空值，得到按时间升序的 [ts, value]。 */
    private Map<String, List<List<Object>>> queryRaw(Scope scope, List<Resolved> present) {
        List<String> ids = present.stream().map(Resolved::identifier).toList();
        Map<String, List<List<Object>>> result = new HashMap<>();
        for (Map<String, Object> row : run(HistoryQueryBuilder.raw(scope, ids))) {
            long ts = InfluxTime.epochMillis(row.get("time"));
            for (int i = 0; i < ids.size(); i++) {
                Object value = row.get(HistoryQueryBuilder.valueAlias(i));
                if (value != null) {
                    result.computeIfAbsent(ids.get(i), k -> new ArrayList<>()).add(List.of(ts, value));
                }
            }
        }
        return result;
    }

    /** 聚合模式：数值测点得到 [桶起点, avg, min, max]，状态测点得到 [桶起点, 最后值]；桶内无值的测点不输出该桶。 */
    private Map<String, List<List<Object>>> queryAggregate(Scope scope, List<Resolved> present, Duration bucket) {
        List<AggColumn> columns = present.stream().map(r -> new AggColumn(r.identifier(), r.state())).toList();
        Map<String, List<List<Object>>> result = new HashMap<>();
        for (Map<String, Object> row : run(HistoryQueryBuilder.aggregate(scope, columns, bucket.toSeconds()))) {
            long ts = InfluxTime.epochMillis(row.get("t"));
            for (int i = 0; i < columns.size(); i++) {
                AggColumn column = columns.get(i);
                List<Object> point = null;
                if (column.state()) {
                    Object last = row.get(HistoryQueryBuilder.lastAlias(i));
                    if (last != null) {
                        point = List.of(ts, last);
                    }
                } else {
                    Object avg = row.get(HistoryQueryBuilder.avgAlias(i));
                    if (avg != null) {
                        point = List.of(ts, avg, row.get(HistoryQueryBuilder.minAlias(i)),
                                row.get(HistoryQueryBuilder.maxAlias(i)));
                    }
                }
                if (point != null) {
                    result.computeIfAbsent(column.identifier(), k -> new ArrayList<>()).add(point);
                }
            }
        }
        return result;
    }

    /** 组装一条曲线的元数据与点。 */
    private static SeriesView series(Resolved r, Mode mode, List<List<Object>> points) {
        PropertySpec spec = r.spec();
        return new SeriesView(r.identifier(), spec == null ? null : spec.name(), r.dataType(),
                spec == null ? null : spec.unit(), spec == null ? null : spec.decimals(), enumItems(spec), mode,
                points);
    }

    /** 枚举项（保持物模型中的顺序）；非枚举为 null。 */
    private static List<EnumItem> enumItems(PropertySpec spec) {
        if (spec == null || spec.dataType() != DataType.ENUM) {
            return null;
        }
        return spec.enumLabels().entrySet().stream().map(e -> new EnumItem(e.getKey(), e.getValue())).toList();
    }

    private List<Map<String, Object>> run(SqlQuery query) {
        return influx(() -> client.querySql(props.database(), query.sql(), query.params()));
    }

    /**
     * 执行一次 InfluxDB 调用并映射异常：不可达或 5xx → 503「时序库暂不可用」；其他 HTTP 错误 → 500「历史查询失败」。
     * 原始错误（可能含 SQL）只写日志。
     */
    private <T> T influx(Supplier<T> call) {
        try {
            return call.get();
        } catch (UncheckedIOException e) {
            log.warn("InfluxDB unreachable during history query: {}", e.getMessage());
            throw new ApiException(HttpStatus.SERVICE_UNAVAILABLE, UNAVAILABLE);
        } catch (InfluxHttpException e) {
            if (e.status() >= 500) {
                log.warn("InfluxDB error during history query: {}", e.getMessage());
                throw new ApiException(HttpStatus.SERVICE_UNAVAILABLE, UNAVAILABLE);
            }
            log.error("History query rejected by InfluxDB", e);
            throw new ApiException(HttpStatus.INTERNAL_SERVER_ERROR, QUERY_FAILED);
        }
    }
}
```

```java
import dev.conduit.server.device.DeviceDtos.DeviceView;
import dev.conduit.server.device.DeviceService;

import org.springframework.web.bind.annotation.PathVariable;

import org.springframework.web.bind.annotation.RestController;

import java.time.Clock;
import java.util.Map;

/** 设备历史查询接口（V0.2-B spec 2）：参数校验、按当前租户查设备、取物模型，再交给 {@link HistoryService}。 */
@RestController
public class HistoryController {

    private final DeviceService devices;
    private final ThingModelCache thingModels;
    private final HistoryService history;
    private final Clock clock;

    public HistoryController(DeviceService devices, ThingModelCache thingModels, HistoryService history,
                             Clock clock) {
        this.devices = devices;
        this.thingModels = thingModels;
        this.history = history;
        this.clock = clock;
    }

    /**
     * 查询设备若干测点的历史曲线。
     *
     * @param deviceKey  设备 Key；不存在或属于其他租户 → 404
     * @param properties 逗号分隔的测点，1～8 个
     * @param from       起点毫秒（含），与 to 同时给出；都不给时为最近 1 小时
     * @param to         终点毫秒（不含）
     * @return 原始或聚合曲线
     */
    @GetMapping("/api/v1/devices/{deviceKey}/history")
    public HistoryView history(@PathVariable String deviceKey,
                               @RequestParam(required = false) String properties,
                               @RequestParam(required = false) Long from,
                               @RequestParam(required = false) Long to) {
        HistoryRequest request = HistoryRequest.parse(properties, from, to, clock.millis());
        DeviceView device = devices.get(deviceKey);
        Map<String, PropertySpec> model = thingModels.find(device.productKey())
                .map(ProductProfile::properties).orElse(Map.of());
        return history.query(TenantContext.require(), device, model, request);
    }
}
```

**Decisions recorded here:**
- `st` is opt-in (`operatingState = true` only in `SimulatorApplication`). `NoDataLossE2EIT` drives `DeviceSimulator` against a product without a thing model, where every number is stored as **Float64**. The state is constant inside each wall-clock hour and may change at the hour boundary, and it is deterministic across restarts. The value is computed from the report's own `ts`.
- Merge import overwrites the demo properties' name, unit and decimals with the file's values, but only when something is missing. That is acceptable for the demo product. Properties not in the file are untouched (merge, not replace).
- Connect retry builds a **new** MQTT client per attempt and disconnects the failed one at once. package dev.conduit.simulator;

```java
/**
 * 演示电表的运行状态（枚举属性 st「运行状态」：0 停机、1 运行、2 检修），用于在历史页演示状态阶梯线。
 * 按 deviceKey 与整点小时序号确定性生成：同一小时内不变，到整点时可能切换；约 80% 的（设备, 小时）为运行，
 * 停机与检修各约 10%。重启模拟器不会改变已过去时段的状态。
 */
public final class OperatingState {

    public static final String IDENTIFIER = "st";
    public static final long STOPPED = 0;
    public static final long RUNNING = 1;
    public static final long MAINTENANCE = 2;

    private static final long HOUR_MS = 3_600_000L;

    private OperatingState() {
    }

    /**
     * 设备在某一时刻所在小时的状态。
     *
     * @param deviceKey   设备 Key（不同设备的状态序列互不相同）
     * @param epochMillis 上报时间（毫秒）
     * @return {@link #STOPPED}、{@link #RUNNING} 或 {@link #MAINTENANCE}
     */
    public static long at(String deviceKey, long epochMillis) {
        long hour = Math.floorDiv(epochMillis, HOUR_MS);
        long bucket = Math.floorMod(mix(deviceKey.hashCode() * 0x9E3779B97F4A7C15L ^ hour), 10L);
        if (bucket < 8) {
            return RUNNING;
        }
        return bucket == 8 ? STOPPED : MAINTENANCE;
    }

    /** SplitMix64 的末端混合：把相邻的输入（相邻小时、相近的哈希值）打散成均匀分布。 */
    static long mix(long z) {
        z = (z ^ (z >>> 30)) * 0xBF58476D1CE4E5B9L;
        z = (z ^ (z >>> 27)) * 0x94D049BB133111EBL;
        return z ^ (z >>> 31);
    }
}
```

```java
package dev.conduit.simulator;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.time.Duration;
import java.util.concurrent.ExecutionException;

/**
 * 设备首次连接 MQTT 的重试策略：间隔 2 秒、最多 15 次（约 30 秒）。每失败 5 次打印一条不带堆栈的 WARN，
 * 全部失败才抛出异常（由 SimulatorApplication 打印一次 ERROR 并退出）。
 * 解决重新部署时 EMQX 与 server 同时重启、EMQX 的鉴权回调尚未就绪导致模拟器首次连接即退出的问题。
 */
final class ConnectRetry {

    static final int MAX_ATTEMPTS = 15;
    static final Duration DELAY = Duration.ofSeconds(2);
    static final int WARN_EVERY = 5;

    private static final Logger log = LoggerFactory.getLogger(ConnectRetry.class);

    /** 一次连接尝试。 */
    @FunctionalInterface
    interface Attempt<T> {
        T run() throws Exception;
    }

    /** 两次尝试之间的等待；测试中替换为只记录不睡眠的实现。 */
    @FunctionalInterface
    interface Sleeper {
        void sleep(Duration duration) throws InterruptedException;
    }

    private final int maxAttempts;
    private final Duration delay;
    private final Sleeper sleeper;

    ConnectRetry() {
        this(MAX_ATTEMPTS, DELAY, d -> Thread.sleep(d.toMillis()));
    }

    ConnectRetry(int maxAttempts, Duration delay, Sleeper sleeper) {
        this.maxAttempts = maxAttempts;
        this.delay = delay;
        this.sleeper = sleeper;
    }

    /**
     * 执行 attempt，失败则等待后重试。
     *
     * @param target  日志与异常中描述连接目标的文字，如 "device dk-1 to emqx:1883"
     * @param attempt 一次连接尝试，失败时抛出异常
     * @return 第一次成功的结果
     * @throws IllegalStateException 达到最大次数仍失败；cause 为最后一次的异常
     * @throws InterruptedException  尝试或等待中被中断，立即抛出，不再重试
     */
    <T> T call(String target, Attempt<T> attempt) throws InterruptedException {
        for (int n = 1; ; n++) {
            try {
                return attempt.run();
            } catch (InterruptedException e) {
                throw e;
            } catch (Exception e) {
                String reason = describe(e);
                if (n >= maxAttempts) {
                    throw new IllegalStateException("Cannot connect " + target + " after " + n + " attempts: "
                            + reason, e);
                }
                if (shouldWarn(n)) {
                    log.warn("Cannot connect {} yet (attempt {}/{}): {}", target, n, maxAttempts, reason);
                }
                sleeper.sleep(delay);
            }
        }
    }

    /** 第 failedAttempts 次失败后是否打印 WARN：每 5 次一条。 */
    static boolean shouldWarn(int failedAttempts) {
        return failedAttempts % WARN_EVERY == 0;
    }

    /** 失败原因的简短描述；ExecutionException 取其 cause，便于看出真正的连接错误。 */
    static String describe(Exception e) {
        Throwable t = e instanceof ExecutionException && e.getCause() != null ? e.getCause() : e;
        return t.getClass().getSimpleName() + ": " + t.getMessage();
    }
}
```

```java
    public DeviceSimulator(String host, int port, Duration interval, int messagesPerDevice,
                           Duration completionTimeout, PayloadFormat format) {
        this(host, port, interval, messagesPerDevice, completionTimeout, format, false);
    }

    /**
     * @param messagesPerDevice 每台设备的上报条数，0 表示一直运行
     * @param operatingState    是否附带运行状态 st；只有产品物模型中 st 为 ENUM 时才应开启（列类型全表共享，
     *                          无物模型的产品会把 st 存成浮点列，与演示产品的整数列冲突）
     */
    public DeviceSimulator(String host, int port, Duration interval, int messagesPerDevice,
                           Duration completionTimeout, PayloadFormat format, boolean operatingState) {
        this.host = host;
        this.port = port;
        this.interval = interval;
        this.messagesPerDevice = messagesPerDevice;
        this.completionTimeout = completionTimeout;
        this.format = format;
        this.operatingState = operatingState;
    }

    /** 替换连接重试策略（测试用较短的间隔与次数）。 */
    DeviceSimulator withConnectRetry(ConnectRetry retry) {
        this.connectRetry = retry;
        return this;
    }

    /**
     * 连接全部设备并开始上报。有限模式下等全部消息完成（或超时）后返回，否则一直运行。
     *
     * @throws IllegalStateException 某台设备重试后仍连不上、超时未完成或有消息最终发送失败
     */
    public void run(List<DeviceCredentials> devices) throws InterruptedException {
        boolean finite = messagesPerDevice > 0;
        long intervalMs = interval.toMillis();
        AtomicInteger threadCounter = new AtomicInteger();
        ScheduledExecutorService scheduler = Executors.newScheduledThreadPool(4, r -> {
            Thread t = new Thread(r, "simulator-" + threadCounter.incrementAndGet());
            t.setDaemon(true);
            return t;
        });
        CountDownLatch finished = new CountDownLatch(finite ? devices.size() : 1);
        AtomicInteger failedMessages = new AtomicInteger();
        AtomicInteger doneMessages = new AtomicInteger();
        List<Mqtt5AsyncClient> connected = new ArrayList<>();

        try {
            List<Mqtt5AsyncClient> clients = new ArrayList<>();
            for (DeviceCredentials d : devices) {
                clients.add(connect(d, connected));
            }

            for (int i = 0; i < devices.size(); i++) {
                DeviceCredentials d = devices.get(i);
                Mqtt5AsyncClient client = clients.get(i);
                ReadingGenerator generator = new ReadingGenerator(d.deviceKey().hashCode());
                String topic = "conduit/%s/%s/up/property".formatted(d.productKey(), d.deviceKey());
                AtomicInteger sent = new AtomicInteger();
                AtomicInteger completed = new AtomicInteger();
                AtomicLong lastTs = new AtomicLong();
                long initialDelay = intervalMs * i / Math.max(1, devices.size());

                Runnable onMessageDone = () -> {
                    doneMessages.incrementAndGet();
                    if (finite && completed.incrementAndGet() == messagesPerDevice) {
                        finished.countDown();
                    }
                };

                scheduler.scheduleAtFixedRate(() -> {
                    try {
                        if (finite && sent.get() >= messagesPerDevice) {
                            return;
                        }
                        int seq = sent.incrementAndGet();
                        long ts = Math.max(System.currentTimeMillis(), lastTs.get() + 1);
                        lastTs.set(ts);
                        Map<String, Object> reading = generator.next(intervalMs / 1000.0);
                        if (operatingState) {
                            reading.put(OperatingState.IDENTIFIER, OperatingState.at(d.deviceKey(), ts));
                        }
                        byte[] payload = format.encode(d.deviceKey() + "-" + seq, ts, reading);
                        publish(scheduler, client, d.deviceKey(), topic, payload, 1, onMessageDone, failedMessages);
                    } catch (RuntimeException e) {
                        log.error("Report task failed for {}", d.deviceKey(), e);
                        if (finite) {
                            failedMessages.incrementAndGet();
                            onMessageDone.run();
                        }
                    }
                }, initialDelay, intervalMs, TimeUnit.MILLISECONDS);
            }

            log.info("Simulating {} devices every {} ms", devices.size(), intervalMs);
            if (finite) {
                boolean completedInTime = finished.await(completionTimeout.toMillis(), TimeUnit.MILLISECONDS);
                if (!completedInTime) {
                    throw new IllegalStateException("Simulator did not finish within " + completionTimeout
                            + ": " + doneMessages.get() + " of " + (long) devices.size() * messagesPerDevice
                            + " messages done, " + failedMessages.get() + " failed");
                }
                if (failedMessages.get() > 0) {
                    throw new IllegalStateException(failedMessages.get() + " of "
                            + (long) devices.size() * messagesPerDevice + " messages failed to publish");
                }
            } else {
                finished.await();
            }
        } finally {
            scheduler.shutdownNow();
            for (Mqtt5AsyncClient c : connected) {
                disconnectQuietly(c);
            }
        }
    }

    /**
     * 连接一台设备，失败时按 connectRetry 重试。每次尝试新建客户端；失败的客户端立即断开（停止其自动重连），
     * 成功的加入 connected，由 run 结束时统一断开。
     *
     * @throws IllegalStateException 重试次数用尽
     */
    private Mqtt5AsyncClient connect(DeviceCredentials d, List<Mqtt5AsyncClient> connected)
            throws InterruptedException {
        return connectRetry.call("device " + d.deviceKey() + " to " + host + ":" + port, () -> {
            Mqtt5AsyncClient client = buildClient(d);
            try {
                client.connect().get(CONNECT_TIMEOUT_MS, TimeUnit.MILLISECONDS);
            } catch (Exception e) {
                disconnectQuietly(client);
                throw e;
            }
            connected.add(client);
            return client;
        });
    }

    private Mqtt5AsyncClient buildClient(DeviceCredentials d) {
        return MqttClient.builder().useMqttVersion5()
                .identifier(d.deviceKey())
                .serverHost(host).serverPort(port)
                .automaticReconnectWithDefaultConfig()
                .simpleAuth().username(d.deviceKey()).password(d.secret().getBytes(StandardCharsets.UTF_8))
                .applySimpleAuth()
                .buildAsync();
    }

    /** 断开客户端；对从未连上的客户端也会停止其自动重连循环。断开本身的失败只记日志。 */
    private static void disconnectQuietly(Mqtt5AsyncClient client) {
        try {
            client.disconnect().join();
        } catch (RuntimeException e) {
            log.debug("Disconnect failed: {}", e.getMessage());
        }
    }

    private void publish(ScheduledExecutorService scheduler, Mqtt5AsyncClient client, String deviceKey,
                         String topic, byte[] payload, int attempt, Runnable onDone, AtomicInteger failed) {
        client.publishWith().topic(topic).qos(MqttQos.AT_LEAST_ONCE).payload(payload).send()
                .whenComplete((result, error) -> {
                    String problem = error != null ? String.valueOf(error.getMessage()) : problemOf(result);
                    if (problem == null) {
                        onDone.run();
                        return;
                    }
                    log.warn("Publish failed for {} (attempt {}): {}", deviceKey, attempt, problem);
                    if (attempt >= MAX_PUBLISH_ATTEMPTS) {
                        failed.incrementAndGet();
                        onDone.run();
                        return;
                    }
                    try {
                        scheduler.schedule(() -> {
                            try {
                                publish(scheduler, client, deviceKey, topic, payload, attempt + 1, onDone, failed);
                            } catch (RuntimeException e) {
                                log.error("Retry failed for {}", deviceKey, e);
                                failed.incrementAndGet();
                                onDone.run();
                            }
                        }, RETRY_DELAY_MS, TimeUnit.MILLISECONDS);
                    } catch (RuntimeException e) {
                        // scheduler already shut down: the run is over, nothing left to account for
                        log.debug("Retry not scheduled for {}: {}", deviceKey, e.getMessage());
                    }
                });
    }

    private static String problemOf(Mqtt5PublishResult result) {
        if (result == null) {
            return null;
        }
        if (result.getError().isPresent()) {
            return String.valueOf(result.getError().get().getMessage());
        }
        if (result instanceof Mqtt5PublishResult.Mqtt5Qos1Result qos1) {
            Mqtt5PubAck ack = qos1.getPubAck();
            if (ack.getReasonCode().isError()) {
                return "PUBACK " + ack.getReasonCode();
            }
        }
        return null;
    }
}
```

```ts
/** 历史页的时间范围：快捷范围、框选缩放范围、自定义范围校验与聚合桶文案 */

/** 半开区间 [from, to)，毫秒 */
export interface TimeRange {
  from: number
  to: number
}

export type QuickRangeKey = '1h' | '6h' | '24h' | '7d' | '30d'

const HOUR = 3_600_000
const DAY = 24 * HOUR

/** 快捷范围，顺序即按钮顺序 */
export const QUICK_RANGES: readonly { key: QuickRangeKey; label: string; ms: number }[] = [
  { key: '1h', label: '最近 1 小时', ms: HOUR },
  { key: '6h', label: '最近 6 小时', ms: 6 * HOUR },
  { key: '24h', label: '最近 24 小时', ms: DAY },
  { key: '7d', label: '最近 7 天', ms: 7 * DAY },
  { key: '30d', label: '最近 30 天', ms: 30 * DAY },
]

export const DEFAULT_QUICK_RANGE: QuickRangeKey = '1h'
/** 接口允许的最小跨度 1 分钟 */
export const MIN_SPAN_MS = 60_000
/** 接口允许的最大跨度 30 天 */
export const MAX_SPAN_MS = 30 * DAY

/** 以 now 为终点的快捷范围 */
export function quickRange(key: QuickRangeKey, now: number): TimeRange {
  const item = QUICK_RANGES.find((r) => r.key === key) ?? QUICK_RANGES[0]
  return { from: now - item.ms, to: now }
}

/**
 * 框选缩放得到的查询范围：起止向外取整到毫秒（允许反向框选）；不足 1 分钟时保留起点、向后补足到 1 分钟。
 */
export function zoomTo(start: number, end: number): TimeRange {
  const from = Math.floor(Math.min(start, end))
  const to = Math.max(Math.ceil(Math.max(start, end)), from + MIN_SPAN_MS)
  return { from, to }
}

/** 自定义范围的校验：返回给用户看的错误文案，合法时返回 null */
export function rangeError(range: TimeRange): string | null {
  if (range.from >= range.to) {
    return '开始时间须早于结束时间'
  }
  if (range.to - range.from < MIN_SPAN_MS) {
    return '时间跨度至少 1 分钟'
  }
  if (range.to - range.from > MAX_SPAN_MS) {
    return '时间跨度不能超过 30 天'
  }
  return null
}

/** 聚合桶宽的中文文案，取能整除的最大单位，如 60000 →「1 分钟」 */
export function bucketLabel(ms: number): string {
  if (ms % HOUR === 0) {
    return `${ms / HOUR} 小时`
  }
  if (ms % 60_000 === 0) {
    return `${ms / 60_000} 分钟`
  }
  return `${ms / 1000} 秒`
}
```

```ts
import type { PointView, PropertyView } from '@/api/types'

/** 可选测点：numeric 为 true 的画折线，否则画状态阶梯线 */
export interface PropertyCandidate {
  identifier: string
  label: string
  numeric: boolean
}

/** 最多同时选择的测点数（与接口上限一致） */
export const MAX_SELECTED = 8
/** 默认选中的数值测点数 */
export const DEFAULT_SELECTED = 4

/**
 * 测点候选：物模型中非 TEXT 的属性（按物模型顺序），再加上最新值中出现、物模型未定义的数值或布尔测点。
 * @param model 产品物模型属性
 * @param latest 设备最新值（用于发现没有物模型的测点）
 */
export function propertyCandidates(model: PropertyView[], latest: PointView[]): PropertyCandidate[] {
  const result: PropertyCandidate[] = model
    .filter((p) => p.dataType !== 'TEXT')
    .map((p) => ({
      identifier: p.identifier,
      label: `${p.name}（${p.identifier}）`,
      numeric: p.dataType === 'DOUBLE' || p.dataType === 'INT',
    }))
  const defined = new Set(model.map((p) => p.identifier))
  for (const v of latest) {
    if (defined.has(v.identifier)) {
      continue
    }
    if (typeof v.value === 'number') {
      result.push({ identifier: v.identifier, label: v.identifier, numeric: true })
    } else if (typeof v.value === 'boolean') {
      result.push({ identifier: v.identifier, label: v.identifier, numeric: false })
    }
  }
  return result
}

/** 默认选中：前 4 个数值测点（不足 4 个时全选数值测点） */
export function defaultSelection(candidates: PropertyCandidate[]): string[] {
  return candidates
    .filter((c) => c.numeric)
    .slice(0, DEFAULT_SELECTED)
    .map((c) => c.identifier)
}
```

```ts
export interface ChartContext {
  from: number
  to: number
  bucketMs: number | null
}

/** 图表标题：「名称（标识）」，物模型未定义时只显示标识 */
export function seriesLabel(s: SeriesView): string {
  return s.name ? `${s.name}（${s.identifier}）` : s.identifier
}

/** 是否按状态测点绘制：布尔、枚举，或服务端按 LAST 聚合的测点 */
export function isStateSeries(s: SeriesView): boolean {
  return s.mode === 'LAST' || s.dataType === 'BOOL' || s.dataType === 'ENUM'
}

/** 横轴起点：聚合时向下对齐到桶边界（服务端按 1970 原点分桶，首桶起点可能早于 from），原始模式即 from */
export function axisMin(ctx: ChartContext): number {
  return ctx.bucketMs ? Math.floor(ctx.from / ctx.bucketMs) * ctx.bucketMs : ctx.from
}

/** 数值文本：有 decimals 时按其格式化，有单位时追加单位 */
export function numberLabel(s: SeriesView, value: number): string {
  const text = s.decimals !== null && s.decimals !== undefined ? value.toFixed(s.decimals) : String(value)
  return s.unit ? `${text} ${s.unit}` : text
}

/** 状态值文本：布尔为「是/否」（数值 1/0 同样处理），枚举为对应名称，未定义的值原样显示 */
export function stateLabel(s: SeriesView, value: unknown): string {
  if (typeof value === 'boolean') {
    return value ? '是' : '否'
  }
  if (s.dataType === 'BOOL') {
    return value === 1 ? '是' : value === 0 ? '否' : String(value)
  }
  const item = s.enumItems?.find((e) => e.value === value)
  return item ? item.label : String(value)
}

/** 一个点的提示文本（未转义）：状态取名称；AGG 显示平均/最小/最大；RAW 显示数值 */
export function pointText(s: SeriesView, point: HistoryPoint): string {
  if (isStateSeries(s)) {
    return stateLabel(s, point[1])
  }
  if (s.mode === 'AGG') {
    return `平均 ${numberLabel(s, point[1] as number)} · 最小 ${numberLabel(s, point[2] as number)} · 最大 ${numberLabel(s, point[3] as number)}`
  }
  return numberLabel(s, point[1] as number)
}

function escapeHtml(text: string): string {
  return text.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;')
}

  const point = typeof first?.dataIndex === 'number' ? s.points[first.dataIndex] : undefined
  if (!point) {

function stateParts(s: SeriesView) {

/**
 * 生成一条曲线的 ECharts option：时间横轴固定为查询范围，工具栏只提供框选缩放，提示框按 axis 触发（配合 echarts.connect 联动）。
 * points 为空时仍返回带坐标轴、空序列的 option（界面另行显示「该时段没有数据」）。
 */
export function buildChartOption(s: SeriesView, ctx: ChartContext): EChartsCoreOption {
  const common = {
    animation: false,
    grid: { left: 64, right: 48, top: 24, bottom: 28 },
    toolbox: { right: 8, top: 0, feature: { dataZoom: { yAxisIndex: 'none', title: { zoom: '框选缩放', back: '还原' } } } },
    tooltip: { trigger: 'axis', axisPointer: { type: 'cross' }, formatter: (params: unknown) => tooltipText(s, params) },
    xAxis: { type: 'time', min: axisMin(ctx), max: ctx.to },
  }
  return isStateSeries(s) ? { ...common, ...stateParts(s) } : { ...common, ...numericParts(s) }
}

/**
 * 从 ECharts 的 datazoom 事件中取框选的时间范围。工具栏框选时值在 batch[0].startValue/endValue；
 * 只有百分比（如还原）、为空或反向时返回 null。
 */
export function zoomRangeFromEvent(params: unknown): TimeRange | null {
  const batch = (params as { batch?: unknown } | null)?.batch
  const item = (Array.isArray(batch) ? batch[0] : params) as { startValue?: unknown; endValue?: unknown } | null | undefined
  const from = item?.startValue
  const to = item?.endValue
  return typeof from === 'number' && typeof to === 'number' && to > from ? { from, to } : null
}
```

```ts
/** 可手动启停的轮询 */
export interface VisiblePoller {
  /** 开始（或重新开始）：页面可见时立即执行一次，之后按间隔轮询 */
  start(): void
  /** 停止，页面重新可见也不恢复 */
  stop(): void
  /** 停止并移除页面可见性监听；组件卸载时调用 */
  dispose(): void
  isActive(): boolean
}

/**
 * 创建页面隐藏时自动暂停的轮询（历史曲线自动刷新用）。处于启动状态时：页面隐藏即暂停，重新可见时立即执行一次并恢复轮询。
 * 与 usePolling 不同，它不随组件挂载自动开始，由调用方按需 start/stop。
 * @param task 每次执行的任务（失败不影响后续轮询）
 * @param intervalMs 上一次执行结束到下一次开始的间隔
 */
export function createVisiblePoller(task: () => unknown, intervalMs: number): VisiblePoller {
  let active = false
  let stopTimer: (() => void) | null = null

  const halt = () => {
    stopTimer?.()
    stopTimer = null
  }
  const run = () => {
    halt()
    stopTimer = startPolling(task, intervalMs)
  }
  const onVisibility = () => {
    if (!active) {
      return
    }
    if (document.hidden) {
      halt()
    } else {
      run()
    }
  }
  document.addEventListener('visibilitychange', onVisibility)

  return {
    start() {
      active = true
      if (document.hidden) {
        halt()
      } else {
        run()
      }
    },
    stop() {
      active = false
      halt()
    },
    dispose() {
      active = false
      halt()
      document.removeEventListener('visibilitychange', onVisibility)
    },
    isActive: () => active,
  }
}
```

```ts
/** 设备详情页的标签与路由 query ?tab= 的互相转换：最新值 latest（默认）/ 历史 history */
import type { LocationQuery, LocationQueryValue } from 'vue-router'

export type DeviceTab = 'latest' | 'history'

const TABS: readonly DeviceTab[] = ['latest', 'history']
const DEFAULT_TAB: DeviceTab = 'latest'

/** 把 ?tab= 解析为设备详情页的标签；重复参数取第一个，未知值回到「最新值」 */
export function deviceTabFromQuery(value: LocationQueryValue | LocationQueryValue[] | undefined): DeviceTab {
  const first = Array.isArray(value) ? value[0] : value
  return TABS.includes(first as DeviceTab) ? (first as DeviceTab) : DEFAULT_TAB
}

/** 生成切换标签后的 query，保留其他参数；默认标签不写入地址栏 */
export function deviceTabQuery(current: LocationQuery, tab: DeviceTab): LocationQuery {
  const next: LocationQuery = { ...current }
  delete next.tab
  if (tab !== DEFAULT_TAB) {
    next.tab = tab
  }
  return next
}
```

```vue
 * 设备历史曲线面板（V0.2-B）：工具栏（快捷范围 / 自定义起止 / 测点多选 / 重置缩放 / 刷新）+ 每个测点一张联动小图。

/** 当前要查询的范围：缩放范围优先，其次自定义范围，否则为以当前时间为终点的快捷范围 */
function currentRange(): TimeRange | null {
  if (zoom.value) {
    return zoom.value
  }
  if (rangeKey.value === 'custom') {
    const value = customValue.value
    return Array.isArray(value) ? { from: value[0].getTime(), to: value[1].getTime() } : null
  }
  return quickRange(rangeKey.value, Date.now())
}

/**
 * 按当前状态安排查询：未选测点时清空；快捷范围且未缩放时启动自动刷新（立即查询一次）；
 * 否则停止自动刷新并只查询一次。
 */
function schedule() {
  poller.stop()
  if (selected.value.length === 0) {
    seq.next()
    data.value = null
    disposeCharts()
    return
  }
  if (rangeKey.value !== 'custom' && !zoom.value) {
    poller.start()
    return
  }
  void load(currentRange())
}

/** 查询并渲染；只有最后发出的请求能写入结果，失败时提示错误 */
async function load(range: TimeRange | null) {
  if (!range || selected.value.length === 0) {
    return
  }
  const id = seq.next()
  loading.value = true
  try {
    const res = await historyApi.query(props.deviceKey, selected.value, range.from, range.to)
    if (!seq.isLatest(id)) {
      return
    }
    data.value = res
    await nextTick()
    renderCharts()
  } catch (e) {
    if (seq.isLatest(id)) {
      ElMessage.error(problemMessage(e))
    }
  } finally {
    if (seq.isLatest(id)) {
      loading.value = false
    }
  }
}

/** 记录每个测点的图表容器；元素卸载时 Vue 以 null 调用 */
function setChartEl(identifier: string, el: HTMLElement | null) {
  if (el) {
    chartEls.set(identifier, el)
  } else {
    chartEls.delete(identifier)
  }
}

/** 用最新数据更新图表：复用同一测点的实例，容器已不存在的实例销毁；所有实例加入同一联动分组 */
function renderCharts() {
  const view = data.value
  if (!view) {
    return
  }
  for (const [id, chart] of charts) {
    if (chartEls.get(id) !== chart.getDom()) {
      chart.dispose()
      charts.delete(id)
    }
  }
  const ctx = { from: view.from, to: view.to, bucketMs: view.bucketMs }
  for (const s of view.series) {
    const el = chartEls.get(s.identifier)
    if (!el) {
      continue
    }
    let chart = charts.get(s.identifier)
    if (!chart) {
      chart = echarts.init(el)
      chart.group = group
      chart.on('datazoom', (params: unknown) => onZoom(params))
      charts.set(s.identifier, chart)
    }
    chart.setOption(buildChartOption(s, ctx), true)
    // 让框选缩放处于激活状态，用户直接拖动即可选择范围
    chart.dispatchAction({ type: 'takeGlobalCursor', key: 'dataZoomSelect', dataZoomSelectActive: true })
  }
  echarts.connect(group)
}

function disposeCharts() {
  charts.forEach((chart) => chart.dispose())
  charts.clear()
}

function resizeCharts() {
  charts.forEach((chart) => chart.resize())
}

/** 框选缩放：按选中范围（不足 1 分钟补足）重新查询并暂停自动刷新；联动图表重复触发的同一范围忽略 */
function onZoom(params: unknown) {
  const selection = zoomRangeFromEvent(params)
  if (!selection) {
    return
  }
  const next = zoomTo(selection.from, selection.to)
  if (zoom.value && zoom.value.from === next.from && zoom.value.to === next.to) {
    return
  }
  zoom.value = next
  schedule()
}

function resetZoom() {
  zoom.value = null
  schedule()
}

/** 选择快捷范围：清除自定义范围与缩放 */

  rangeKey.value = key
  customValue.value = ''

    return

  if (error) {
    ElMessage.warning(error)
    return
  }
  rangeKey.value = 'custom'
  zoom.value = null
  schedule()
}

watch(selected, () => schedule())

onMounted(async () => {
  window.addEventListener('resize', resizeCharts)
  try {
    const [model, latest] = await Promise.all([thingModelApi.list(props.productKey), deviceApi.latest(props.deviceKey)])

  }
})

  poller.dispose()
  seq.next()
  window.removeEventListener('resize', resizeCharts)
  disposeCharts()
})
</script>
```
