# Conduit 前端体验优化设计

- 日期：2026-10-15
- 状态：已实现（实施计划 docs/superpowers/plans/2026-10-15-conduit-ui-refresh.md）
- 范围：V0.2-B 之后、V0.2-C 之前的独立子项目，主要是前端，另有两处后端只读改动（`/overview` 接口与产品列表计数）。界面示意已在评审中确认（侧栏、产品列表、设备详情、首页、登录页）。
- 前置：V0.2-B 已完成（设备历史曲线、ECharts 6.1.0）。

## 1. 目标与范围

把现在"能用但都是 Element Plus 默认样子"的界面整理成统一、好找、好看的后台：统一框架（侧栏、顶栏、页头），统一列表页写法，设备详情改为信息卡 + 指标卡片，新增首页总览，重做登录页，支持整体暗色模式和侧栏风格切换。V0.2-C 的用户、租户页面直接套用这里的框架。

不包含：国际化、移动端专门适配（保证窄屏不横向滚动即可）、权限菜单（V0.2-C）、大屏/可视化看板。

## 2. 整体框架

### 2.1 侧栏

- 顶部 Logo（折线图标 + 「Conduit」）。
- 菜单分组，每项带图标（`@element-plus/icons-vue`）：
  - 概览：首页
  - 设备接入：产品、设备
  - 系统管理：用户、租户（本期显示为禁用项，标注「V0.2-C」，不可点击）
- 可折叠：底部「收起菜单」，折叠后只显示图标（悬停显示名称）。窗口宽度 < 820px 时自动折叠。
- 两种风格：**浅色**（白底、选中项浅蓝底蓝字）与**深色**（深蓝灰底、选中项主色底白字），默认深色。
- 菜单高亮按路由归属：产品列表与产品详情归「产品」，设备列表与设备详情归「设备」。

### 2.2 顶栏

- 左侧：全局面包屑，由路由 `meta.breadcrumb` 生成，详情页最后一级显示对象名称（页面加载后通过 `useBreadcrumb` 设置，如「设备接入 / 设备 / 1号楼配电室 电表01」），可点击的上级可跳转。
- 右侧：外观切换按钮、当前租户名称标签、用户头像（用户名首字）+ 下拉菜单（用户名、所属租户、退出登录）。
- 外观切换：弹出面板，两组单选——**主题**：浅色 / 深色 / 跟随系统（默认跟随系统）；**侧栏**：浅色 / 深色。

### 2.3 暗色模式与外观偏好

- 用 Element Plus 自带暗色变量（引入 `element-plus/theme-chalk/dark/css-vars.css`，在 `<html>` 上切换 `dark` 类）。
- 跟随系统时监听 `prefers-color-scheme` 变化实时切换。
- 应用自己的样式全部使用 CSS 变量（`--el-*` 或 `src/styles/tokens.css` 中定义的 `--cd-*`），不写死颜色。
- ECharts 图表随主题切换：传入 `dark` 主题（ECharts 内置）或按 CSS 变量取色，切换时重建或 `setOption` 更新。
- 偏好（主题、侧栏风格、侧栏折叠）存在 `localStorage`（键 `conduit.ui`），读写失败时用默认值，不报错。
- 主色统一为一个蓝（`--el-color-primary`），间距与圆角用一组固定变量。

### 2.4 统一页头与页面元素

- `PageHeader` 组件：标题、可选副标题（一句说明）、右侧操作按钮插槽。所有页面使用。
- 浏览器标签标题跟随页面：`<页面名> · Conduit`，详情页为对象名称。
- 新增 404 页（未匹配路由）：说明页面不存在，提供「回到首页」。
- 默认进入首页（`/` 重定向到 `/home`）。

## 3. 列表页

- `FilterBar` 组件：一行放关键字输入、下拉筛选、「查询」「重置」，窄屏自动换行；回车即查询。
- `useTable` composable：统一处理分页（默认每页 10 条，可选 10/20/50/100）、加载状态、请求序号（丢弃过期响应）、删除后页码修正。产品列表、设备列表、产品详情的设备与属性表都改用它。
- 状态展示组件：
  - `OnlineDot`：在线绿点 + 「在线」，离线灰点 + 「离线」。
  - 启用/禁用用 `el-tag`（成功色 / 灰色）。
  - `RelativeTime`：显示「3 分钟前」，悬停显示完整时间，每分钟自动更新。
- 空状态：`el-empty` + 引导按钮，例如「还没有产品，先创建一个产品」→「新建产品」。
- 加载：首次加载显示表格骨架屏，翻页时只显示表格 loading。
- 产品列表新增「设备（在线/总数）」列（见 5.2）。

## 4. 设备详情

- **设备信息卡**（替换原顶部信息）：图标、名称、在线状态、启用状态标签；下方一行：所属产品（链接）、设备 Key（可复制）、最后上报（相对时间）、创建日期；右侧「连接参数」（原连接参数改为弹窗）、「编辑」。
- **最新值**标签页：
  - 默认**卡片视图**：每个测点一张卡片，显示名称、标识、数值（按小数位）+ 单位、最近 1 小时迷你趋势线、相对时间；布尔/枚举显示文字标签（如「运行」），不画趋势线。
  - 迷你趋势线：一次请求 `GET /devices/{dk}/history`，最多 8 个数值测点、最近 1 小时，取聚合后的平均值；每 60 秒刷新一次（数值本身仍每 5 秒刷新）。超过 8 个数值测点时只给前 8 个画趋势线。
  - 右上角「卡片 / 表格」切换，表格即原表格；选择存入外观偏好。
  - 点击卡片：切到「历史」标签页，并只选中该测点（路由 query `tab=history&props=Ua`）。
- **历史**标签页：支持从 query `props` 读入初始选中测点（逗号分隔，过滤掉不存在的），其余行为不变。

## 5. 首页总览与后端接口

### 5.1 `GET /api/v1/overview`

只读、按当前租户统计：

```json
{
  "productCount": 2, "propertyCount": 15,
  "deviceCount": 200, "enabledCount": 200, "disabledCount": 0, "onlineCount": 100,
  "deadLastHour": { "total": 3, "byReason": { "FIELD_REJECTED": 3 } },
  "recentDevices": [ { "deviceKey": "…", "name": "1号楼配电室 电表01", "productKey": "…", "productName": "三相电表（演示）", "lastReportAt": 1760510528000 } ],
  "products": [ { "productKey": "…", "name": "三相电表（演示）", "deviceCount": 100, "onlineCount": 100 } ]
}
```

- 设备数、启用数、按产品设备数：PostgreSQL 分组计数（租户拦截器过滤）。
- 在线数、最后上报时间：批量读 Redis 在线状态（`PresenceStore.getAll`）与最新值时间；`recentDevices` 取最后上报时间最近的 5 台。
- 最近 1 小时死信：从死信流 `conduit:stream:dead` 读取最近 1 小时的条目（`XREVRANGE` 到 1 小时前为止，最多 10 000 条），只统计 `pk` 属于当前租户产品的条目，按 `reason` 分组。
- 设备数较多时的代价：本期按"租户设备全部读出"实现，在 `docs/backlog-v0.2.md` 记录 1 万台规模时改为增量计数。
- Redis 不可用时在线相关字段返回 `null`，其余照常；前端显示「—」。

### 5.2 产品列表计数

`ProductView` 增加 `deviceCount`、`onlineCount` 两个字段（列表与详情都返回），在线数同样来自 `PresenceStore`。

### 5.3 首页布局

- 4 个指标卡：产品（副文「共定义 N 个属性」）、设备（「已启用 N · 已禁用 N」）、在线设备（数字 + 在线率进度条）、最近 1 小时死信（数字 + 按原因的简述，0 时显示「无」）。
- 「最近上报的设备」列表（点击进入设备详情）与「按产品统计」列表（点击进入产品详情）。
- 每 30 秒自动刷新（页面隐藏时暂停）。

## 6. 登录页

左右两栏：左侧深色品牌区（Logo、「Conduit 设备接入平台」、一句说明、底部装饰性折线图形），右侧登录表单；窄屏时上下排列。登录逻辑与校验不变；错误提示显示在表单内。

## 7. 代码结构

- `src/styles/tokens.css`：应用自己的设计变量（含暗色值）。
- `src/stores/ui.ts`：外观偏好（主题、侧栏风格、折叠、最新值视图），读写 `localStorage`。
- `src/composables/`：`useTable`、`useBreadcrumb`、`useTheme`（应用主题、监听系统变化）。
- `src/components/`：`PageHeader`、`FilterBar`、`OnlineDot`、`RelativeTime`、`MetricCard`、`Sparkline`（ECharts 小图）、`AppearancePanel`。
- `src/layouts/AppLayout.vue`：新侧栏与顶栏。
- `src/views/`：新增 `HomeView.vue`、`NotFoundView.vue`；改造登录、产品列表、产品详情、设备列表、设备详情。
- 后端：`dev.conduit.server.overview`（`OverviewController`、`OverviewService`、DTO），`ProductService` 增加计数。
- 所有新增与修改代码遵守 CLAUDE.md 注释规则。

## 9. 完成标准

在演示环境上：

1. 侧栏可在浅色 / 深色间切换、可折叠，刷新后保持；主题可在浅色 / 深色 / 跟随系统间切换，所有页面（含图表、对话框）在深色下可读。
2. 每个页面都有面包屑与统一页头；未知地址显示 404 页。
3. 产品列表显示「设备（在线/总数）」，筛选栏、相对时间、在线圆点、空状态生效；所有分页默认每页 10 条。
4. 设备详情显示信息卡与指标卡片（含迷你趋势线、运行状态文字），点击 Ua 卡片进入「历史」且只选中 Ua。
5. 首页显示 4 个指标卡与两个列表，数值与设备列表一致；另一个租户看到的是自己的数据。
6. 登录页为新样式，浅色/深色下都可读。
