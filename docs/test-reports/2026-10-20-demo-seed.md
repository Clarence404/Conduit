## 3. 已知边界

- Flyway 只固化关系库中的稳定资产。在线状态、最新值和历史曲线属于 Redis / InfluxDB，必须在模拟器启动后才会出现。
- 种子设备使用不可直接接入的占位密钥哈希；模拟器通过平台 API 重置所模拟设备的密钥后再连接 MQTT。
- 独立部署默认把平台管理员密码传给模拟器，因此会发现并模拟全部预置演示租户；本地 IDE 启动仍需自行配置未入库的 `SIM_PLATFORM_PASSWORD`。
- 未执行真实生产环境部署与长期压测；本次只验证全新/升级数据库、完整自动化回归和容器化 e2e。
